Projetos
🤖 BLOB — Atendente virtual com IA
Agente de atendimento que conversa com o visitante do site, apresenta planos e capta leads automaticamente — com redirecionamento elegante para o WhatsApp caso a IA esteja indisponível.

Funcionalidades

💬 Chat interativo com respostas por IA
🎯 Apresentação de planos (Lojinha Express / Premium)
📲 Captura de leads com fallback para WhatsApp
🛡️ Mensagem de instabilidade amigável quando a API não responde
🔑 Chaves de API protegidas via variáveis de ambiente (Vercel)
Demo: 👉 hypelab-xi.vercel.app

👗 VITRINNI PRO — Engine de catálogo white-label
Sistema onde um único template ("tela") renderiza qualquer loja a partir de um arquivo de dados ("pintura"), editável por um painel admin — sem mexer no código. Um motor, várias lojas.

Arquitetura

Tela — o motor: desenha header, vitrine, carrossel, animações e presets cromáticos
Pintura — o arquivo de dados: nome da loja, produtos, cores, slides
Admin — painel visual que edita a pintura sem código
Funcionalidades

🏪 Cadastro da loja: nome, slogan, WhatsApp, Instagram, logotipo
📦 Cadastro de produtos: nome, preço, categoria, tamanhos, cores, foto, descrição
🖼️ 3 vitrines: grade, roleta e lista
🎨 9 presets cromáticos premium
✨ Animação do logo e da marca + carrossel promocional
Demo: 👉 catalogo.hypelabofc.site

Tecnologias
HTML • CSS • JavaScript • API de IA • Renderização orientada a dados • Vercel • Domínio próprio
